Rate limiter reference

Policy: one shared rolling bucket per IP across both booking email verification endpoints: 20 allowed requests in the preceding hour.

  1. Extract the direct peer IP from r.RemoteAddr with net.SplitHostPort; handle parse errors. Treat forwarded headers as untrusted unless a trusted proxy is configured.
  2. Lock shared state. At one captured time, discard timestamps at or before now.Add(-time.Hour).
  3. If 20 timestamps remain, unlock and return 429. Otherwise append the current timestamp and unlock.
  4. Call next.ServeHTTP(w, r) after releasing the lock.

Keep the check and append inside the same lock. Remove inactive IP entries so the map does not grow forever. A restart resets the map; multiple instances do not share it.

Tests should cover 20 allowed, 21st blocked, separate IPs, expiry at the one-hour boundary, concurrent requests, and both endpoints sharing the same limiter. Use an injected clock and run the race detector.
